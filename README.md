# Doors of Words

An educational website designed to support literacy and language learning, developed by four AUAF students as part of ITC Group 1.

## Features
- Book sections for beginner, intermediate, and advanced learners.
- A language-learning guide.
- Search through a predefined list of learning resources.
- An interactive team section and contact page.
- Responsive navigation and image carousels.

## Technologies
HTML, CSS, JavaScript, and Bootstrap 5.

## How to Run
Download and extract the project, then open `index.html` in a browser. Internet access is needed for Bootstrap and externally hosted images. 

## Project Status
A front-end academic prototype. Book downloads are placeholders, and the contact form requires a valid Formspree endpoint.
